READY FOR STREAMLIT COMMUNITY CLOUD

Upload the CONTENTS of this folder to a GitHub repository (not the ZIP itself).
Required app settings in Streamlit Community Cloud:
- Main file path: app.py

For Demo mode: no secret is required.
For AI + UPPG RAG mode, add this in Streamlit App Settings > Secrets:
OPENAI_API_KEY = "your-key-here"
OPENAI_MODEL = "gpt-5-mini"

Do NOT upload .streamlit/secrets.toml if you create one locally.
